# 字符串函数

## 1.求字符串长度

size_t strlen(const char *s)

实现：

```c
int m_strlen(const char *s)
{
    int size=0;
    if(s == NULL)
    	return 0;
    while(*s++ != '\0')
    {
        size++;
    }
    return size;
}
```

思路：比如字符串”hello”只需要判断结尾不为‘\0’说明还没到最后，就大小加1



## 2.字符串拷贝函数

函数原型： char *strcpy(char *dest, const char *src)

实现

```c
char *m_strcpy(char *dest,const char* src)
{
	char* ret = dest;
	while(*src != '\0')
	{
		*dest++=*src;
		src++;
	}
	return ret;
}
```

思路：比如字符串”hello”只需要判断结尾不为‘\0’说明还没到最后，就把src里面的值给dest，之后两个地址都增加，继续完成赋值



## 3.比较字符串是否相等

函数原型：

int strcmp(const char *s1, const char *s2);

  函数返回值说明：

  s1== s2  ----->0

  s1 < s2  ----->负数 比如字母f <g 就会返回-1

  s1 > s2 ------>正数   



实现

```c
int m_strcmp(const char *s1,const char *s2)
{
	assert(s1 != NULL && s2 != NULL);
    while(*s1 && *s2 && (*s1 == *s2))
	{
		s1++;
        s2++;
	}
    return (*s1-*s2);

}
```

思路：如果有其中一个为空，说明该字符串到尾巴，就要停止比较，返回比较直，



## 4.拼接字符串函数

函数原型：

char *strcat(char *dest,const char *src)

实现

```c
char *m_strcat(char *dest,const char* src)
{
    char* ret = dest;
    while( *dest!='\0' )
    {
        dest++;
    }   
    while( *src != '\0')
    {
        *dest++ = *src++;
    }
    return ret;
}
```

思路：很简单，只需要找到dest的最后即’\0’位置即可，之后在把src的值给dest,知道src的’’\0’,这个时候就结束拼接

注意一点的是，dest使用的时候开辟的空间要足够大，不然会导致拼接内存溢出



## 5.memset

复制字符 c（一个无符号字符）到参数 **str** 所指向的字符串的前 **n** 个字符

函数原型：

void *memset(void *s, int c, size_t n);

实现

```c
void *m_memset(void *s,int c,size_t n)
{
	void *ret = s;
    while(n--)
    {
        *(char*)s++ = (char)c;
    }
	return ret;
}
```

思路：只需要找到s的n位置，之后再赋值即可

这里注意类型强转


思路：要考虑输入字符串前面是否有空格，考虑正负，考虑输入的是0-9的字符串而不是其他
